POLYUNION 二维码网页工具 V0.1
============================================================

这个压缩包可以直接上传到 GitHub Pages。

【压缩包内文件】

index.html
    网页界面、摄像头扫码、相册增强识别、GB18030/GBK解码都在这里。

manifest.webmanifest
    让 iPhone 可以把网页加入主屏幕。

service-worker.js
    缓存网页文件，后续打开更快。

icons
    iPhone和安卓主屏幕图标。

.nojekyll
    告诉 GitHub Pages 直接发布静态文件。

【程序功能】

1. iPhone、安卓和电脑浏览器都可以打开。
2. 调用后置摄像头实时扫码。
3. 从相册选择静止图片解析。
4. 相册模式尝试：
   - 整图和自动二维码候选区域
   - 0°、90°、180°、270°旋转
   - 灰度
   - 红通道
   - 自动对比度
   - Otsu二值化
   - 红通道固定阈值
5. 自动尝试 UTF-8、GB18030、GBK、Big5 等编码。
6. 自动修正二维码 JSON 中的大写 NULL。
7. 图片和摄像头画面不上传服务器。
8. 长字段自动换行。
9. 支持复制结果。
10. 支持添加到 iPhone 主屏幕。

【注意】

- 摄像头必须通过 HTTPS 网址使用。
- 直接双击 index.html 时，可以看界面和试相册，但摄像头通常不能打开。
- 网页二维码引擎使用固定版本的 ZXing Browser 0.1.5，通过网络加载。
- 第一次打开网站时需要联网；浏览器缓存以后，后续加载会更快。
- GitHub仓库公开时，别人能看到网页程序代码，但看不到你扫描过的图片和内容。
